# 左侧文库与右侧检查器布局

2026-10-18，修正 ContentView 分栏结构。

右侧 inspector 原先嵌在 NavigationSplitView 的 detail 内。默认可见表格列最小宽度合计 468 点，加上左右栏最小宽度 190/330 点，已超过窗口允许的 980 点宽度。现在 inspector 属于完整 NavigationSplitView，中心表格容器允许收缩并保持原生横向滚动，使用 balanced 分栏；工具栏保持窗口根层级，右栏文件拖入入口保留。

使用独立合成文库运行签名 QA 应用：

- 宽窗口和约 980 点窄窗口中，侧栏、检查器和全部主工具栏按钮保持在窗口内。
- 窄窗口隐藏、再展开左栏后，右栏分隔位置保持 590 点，宽约 390 点；没有把右侧按钮或面板推到窗外。
- 独立隐藏、再打开检查器后，研读选项、输出按钮、历史记录与左右栏内容正常，添加/导出/检查器按钮仍可见，没有异常工具栏溢出项。
- 正式应用部署前正常退出，重新构建并验证启动与代码签名；未生成或改动真实文献资料。

这次为窗口布局修复，以原生交互与编译验证为主，未新增模拟布局实现的单元测试。
