# PaperShelf 研读扩展验收记录

日期：2026-10-18；环境：本机 Apple Silicon、macOS、SwiftPM、Python 3.14.7。

本记录区分软件流程验证与科学内容核验。AI 学习稿始终标为待研究者核验，测试通过不代表论文结论、模型复现或字段数据获得科学接受。

## 原生应用流程

独立 QA 书库位于 `~/Library/Application Support/PaperShelfQA/`，没有覆盖生产书库。

- 从应用导入 `Examples/sample.pdf`，实际在线精读完成，生成学习 HTML / Markdown、完整来源、字段表、证据图谱和可运行 Agent。该文件是明确标注的合成测试文档。
- 退出再启动，生成历史和产物入口恢复。失败运行保留并显示失败状态，缺失产物按钮不显示为可用；取消后保留既有产物。
- 应用内实际在线提问“这份样本文档包含哪些内容？请引用原文，并明确它是不是研究论文。”返回中文回答、`p1-g3`/`p1-g4` 引用，并明确该输入不是已发表研究论文。
- 问答曾因服务要求 JSON 字面指令返回 HTTP 400；统一补充 JSON 输出指令后，同一实际操作成功，严格协议端点回归覆盖此问题。
- 实际打开字段校对，确认无反应体系证据的字段保持空值，填写理由后另存；连续两次校对生成独立目录、CSV、TSV、证据图谱及完成标记，审计链累积而非覆盖。第一次操作保留了应用默认操作者 Ben，第二次以 Codex QA 明确说明实际为自动化验收，不代表用户的科学确认。
- 校对完成后，界面明确显示字段和表格使用最新校对版本，原学习指南保持生成时内容。
- 重启后再次恢复最新校对版本；在图谱窗口查询 `Bayesian chemical reaction neural network uncertainty`，实际连接生产 Neo4j，返回 10 条事实卡片。展开 B-CRNN 与贝叶斯推断关系的“出处与时间”，可见图谱时间、完整来源 episode 和原 PDF / Markdown 文件按钮。该检查完成时全篇导入仍在继续，不将局部可检索等同全篇入库完成。
- 实际取消测试任务恢复可操作状态。独立编译的进程取消 harness 验证父进程、后代和忽略 TERM 的后代停止，独立无关进程仍运行。
- Python 后端使用应用支持目录内的受管运行环境；禁写字节码，避免导入时写入签名应用资源。设置保存凭据在后台执行，避免等待钥匙串时冻结主界面。
- 对只读安装源副本执行真实 pip 安装，867 项内容 SHA 与权限前后相同，退出码为 0，私有构建 staging 已清理。
- 纯凭证规划器的真实 Swift 编译 harness 有 26 项通过：覆盖默认地址、旧别名、跨服务密钥隔离、独立嵌入密钥、继承环境优先、离线命令不读取模型凭据等，没有读取真实密钥。
- 凭据读取增加取消与 30 秒超时：等待中的系统调用不能阻止任务取消，迟到结果不会启动文献处理。106 项假读取器检查覆盖成功、错误、启动前取消、读取中取消、超时及 100 次完成/取消/超时竞态；没有读取真实钥匙串，见 `independent-qa/async-secret-loader-harness.swift`。
- 正式书库中的纯中文问题“第一个合成反应案例的模拟时间步长是多少？原文是否明确给出了秒这一物理单位？”实测通过。Agent 由零词面命中扩展三个英文查询，正确把 `p8-g87` 排第一，回答为 0.4 time unit、未明确写作秒；正文引用与来源列表一致。跨语言召回、英文复数、子问题覆盖、完整同页上下文、数学括号与组合引用、引用修复、占位符拒绝和诊断隐私回归最终共 20 项通过。最终实机再次回答 Case I 为 0.4 time unit，并引用 p8-g87，没有擅自补写秒。
- 正式书库 B-CRNN 的纯中文问题“文中预测区间是否等于95%置信区间？”最终实测成功：引用 p5-g202、p7-g246、p7-g280、p8-g309、p9-g350、p10-g356、p10-g366 报告原文的 4 standard deviations，明确仅据当前证据无法判断等于 95% 置信区间；没有擅自解释为 ±4σ 或换算覆盖概率。两篇最终在线请求均通过引用集合校验，记录为 `independent-qa/final-native-agent-qa.json`。
- 原生截图检查发现长答案底部被状态栏遮挡，已把状态栏移入明确占位的垂直布局。重新构建和正常启动后，实际多行中文回答可滚动至最后一句，底部留白完整。
