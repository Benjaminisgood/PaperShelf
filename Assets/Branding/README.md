# PaperShelf identity

Original PaperShelf artwork: layered ivory pages and a cyan bookmark on a sapphire glass tile. The transparent PNG is the editable source image; the ICNS contains 16–1024 px macOS representations. No Lattice artwork was used.

Created using the built-in image generation tool. Packaging uses Apple's sips and iconutil; regenerate with `bash script/build_icon.sh`. The app bundle uses `CFBundleIconFile=PaperShelf`, including Finder, Dock, and the standard About panel.

## Generation prompt

Use case: logo-brand. Asset: final original macOS application icon for PaperShelf, a scholarly paper library and research reading app. Create one polished 1024x1024 square icon, centered on a transparent canvas. A rounded-square sapphire blue glass tile with generous transparent outside corner area, soft precise edge highlights and subtle dimensional depth, suitable beside Apple's latest macOS app icons. Inside the tile an elegant clearly legible ivory open paper/book shape with two or three layered pages, and a single small cyan bookmark integrated into the spine, suggesting an organized research bookshelf. Strong simple silhouette legible at 32 pixels. Calm academic and premium, no tiny decorative elements. Straight-on centered view, not tilted. No letters, no text, no wordmark, no watermark, no atoms, no robot, no sparkle symbols, no existing brand assets. Background outside the rounded tile must be truly transparent.
